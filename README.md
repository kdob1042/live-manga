# Live Manga

触れたコマが動画になる、漫画の読者アプリ。縦スクロールで読み進めます。

制作の流れは **story-libraryで執筆 → [manga-mac](https://github.com/kdob1042/manga-mac)で漫画制作・書き出し → live-mangaで確認・閲覧**。原稿の`work.json`を直接読み込まず、検証済みの漫画パッケージを受け取ります。配信契約の正本は本リポジトリの`contracts/`です。

## 読む・確認する

- 作品一覧から話を選び、読み終わったら「次の話へ」。左下の取っ手で目次、作品トップ、作品一覧を開けます。
- マークのあるコマを押すと再生。スマホは長押し、PCは再生中の再クリックで拡大します。動画は操作時だけ取得し、同時再生は1コマです。
- 終了、画面外、バックグラウンド移動で静止画に戻ります。指を動かした場合はタップ・長押しを取り消し、スクロールを優先します。
- コマ内再生中はそのコマの文字を隠します。読書メニューで無効化できます。素材に焼き込まれた文字は消せません。
- 拡大時は動画全体を表示し、再生・シーク・音声の操作を必要時だけ出します。
- 読書メニューに本文のテキスト表示があります。キーボード操作とブラウザのズームを使えます。
- 制作途中の非公開プレビューは閲覧用キーで開きます。「最新版を開く」で更新し、失敗時は表示中の版を残して再試行できます。読書中の自動更新はしません。

## ローカルで起動

Node 22+で実行します。

```sh
npm ci
npm run dev
```

人工サンプル3ページを自動復元します。既存素材を再利用した操作確認用で、AI生成作品ではありません。ビルドは`npm run build`。サンプル再生成の`npm run fixture:generate`だけFFmpeg/ffprobe、Python/Pillow、DejaVu Sansが必要です。
